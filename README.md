# Maquettage-d-un-site-avec-SIGMA
Devoir de maquettage
Projet réalisé à partir du brief « Maquetter un site avec Figma ».

## Contenu

- 5 wireframes desktop :
  - Accueil
  - Produit
  - Commande
  - À propos
  - Assistance
- 5 wireframes mobiles correspondant aux mêmes écrans
- 1 prototype visuel desktop de la page d’accueil
- 1 prototype visuel mobile de la page d’accueil
- 1 schéma d’enchaînement des écrans
- Une charte de styles et un plan de tâches

## Import dans Figma

1. Créer un nouveau fichier Figma nommé `Probeats_Ecommerce`.
2. Créer les pages : `00_Styles`, `01_Wireframes_Desktop`, `02_Wireframes_Mobile`, `03_Prototype`, `04_User_Flow`.
3. Glisser-déposer les fichiers SVG du dossier `wireframes/desktop`.
4. Glisser-déposer les fichiers SVG du dossier `wireframes/mobile`.
5. Importer les deux SVG du dossier `prototype`.
6. Importer `docs/schema_enchainement.svg`.
7. Transformer les éléments récurrents en composants : navigation, footer, boutons, cartes produit, champs de formulaire.
8. Appliquer Auto Layout aux boutons et aux blocs de contenu.
9. Ajouter les interactions du prototype :
   - `Découvrir le casque` → page Produit
   - `Ajouter au panier` → page Commande
   - `Produits` → Produit
   - `À propos` → À propos
   - `Assistance` → Assistance
   - `Compte` → overlay Connexion
10. Enregistrer une copie locale au format `.fig`.

## Grille recommandée

### Desktop
- Frame : 1440 px
- 12 colonnes
- Marges : 48 px
- Gouttières : 24 px
- Padding des blocs : 24 px

### Mobile
- Frame : 390 px
- 4 colonnes
- Marges : 20 px
- Gouttières : 16 px
- Padding des blocs : 24 px
